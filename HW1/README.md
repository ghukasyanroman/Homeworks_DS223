# Posha diffusion analysis using the Bass model

Roman Ghukasyan | Marketing Analytics

I use U.S. microwave ownership to estimate p, q and historical M, then forecast
Posha adoption with a separate Fermi estimate of the U.S. household market.

## How to run in VS Code

Use Python 3.10 or newer. Extract the ZIP and open the inner `posha_bass_model`
folder in VS Code. Install the packages in that folder's terminal:

```bash
python -m pip install -r requirements.txt
```

Open `posha_analysis.ipynb` and select the Python environment where the packages
are installed. Click Restart and Run All, then save the notebook with its outputs.
Use the Python and Jupyter extensions in VS Code if needed.

The notebook extracts the raw CSV, fits the model, creates the forecast CSV and
both charts, and creates `report/report.pdf` in its final cell. It works offline
after installing the packages. No separate runner, LaTeX or PDF converter is needed.

## Report workflow

The analysis is in the notebook. The written report is `report/report_source.md`,
with tables and discussion based on the notebook results. The final notebook
cell calls `build_report.py` to turn that Markdown and the generated charts into
the PDF. It reads the Markdown without rewriting it.

If changing the analysis or assumptions, update the tables and discussion in
`report_source.md` before running the final cell again.

## Main results and assumptions

Estimated microwave p = 0.00050491 and q = 0.36524560 per year.
Historical M = 68.52 million household equivalents on a fixed 1978 base of
77 million. Ownership is a proxy for adoption, not a count of unique buyers.

Posha M = 132,737,146 * 20% * 2.5%, or about 664,000 households.
The two percentages and exact starting count of 1,000 households are planning
assumptions. The forecast reaches about 7,300 households by 2030 and 47,100 by
2035. It is a possible scenario based on a comparison product.
